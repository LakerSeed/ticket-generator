## Como funciona

O site tem como intuito servir como um gerador de tickets onde o usuário irá inserir seus dados nos campos do formulário e arpós isso ele será redirecionado para uma página, onde um ticket será gerado com base nos dados do usuário.

## Como rodar o projeto

Ao baixar o projeto pelo repositório do github, instale as dependências do projeto com o comando <br>
*npm i*<br>
Após isso, no terminal utilize o script npm run dev para rodar o projeto.
